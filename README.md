# BiliZen
> 哔哩哔哩别烦我 | 隐藏 B 站视频页右侧推荐列表，沉浸学习

一个 Tampermonkey 用户脚本，自动隐藏 B 站视频播放页右侧的"相关推荐视频"列表，保留 UP 主信息、合集/分 P 和弹幕列表。支持右下角浮动开关 + `Alt+F` 快捷键切换，记忆偏好。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. [点此安装](https://raw.githubusercontent.com/Ttungx/BiliZen/main/bilibili-focus-mode.user.js)（或手动将 `bilibili-focus-mode.user.js` 内容粘贴到新脚本中保存）
3. 访问任意 B 站视频页，右侧推荐自动隐藏

## 支持的页面

`/video/*` `/list/*` `/bangumi/*`
